# Software-de-Simulacion-y-Aprendizaje-Regla-de-la-palanca
Este simulador interactivo está diseñado para facilitar el análisis de diagramas de fase binarios. Podrás cargar gráficos reales de la literatura, calibrar las escalas de temperatura y composición, y determinar instantáneamente las fracciones másicas y químicas de las fases conjugadas mediante la Regla de la Palanca.
